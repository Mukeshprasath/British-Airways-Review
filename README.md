# British Airways Review – Interactive Dashboard

📊 This Tableau project explores **British Airways customer reviews (2016–2023)** through an interactive dashboard. It provides a clear view of customer satisfaction across multiple service dimensions, helping identify strengths and improvement areas.

The dataset covers traveller types, seat classes, aircraft models, countries, and time periods. Using Tableau, the data is transformed into visual insights that highlight performance trends over time, geographical patterns, and aircraft-level comparisons.

### Key Features

* **Overall Rating (Avg: 4.2)** with trends from 2016–2023.
* **Category Ratings:** Cabin Staff (3.3), Value for Money (2.8), Seat Comfort (2.9), Food (2.4), Entertainment (1.4).
* **Trend Analysis:** Monthly fluctuations in customer satisfaction.
* **Geographical Insights:** Ratings mapped by country.
* **Aircraft Comparison:** Boeing 747 rated highest (4.7), while other models show mixed results.
* **Interactive Filters:** Traveller type, seat type, aircraft group, continent, and date range.

### Insights

* Boeing 747 received the highest satisfaction (4.7).
* Food and Entertainment scored lowest, showing areas for improvement.
* Ratings show fluctuations year to year, influenced by traveller type and seat class.

### Outcome

The dashboard provides an **end-to-end overview of customer experiences**, helping stakeholders understand patterns in feedback and uncover actionable insights for service enhancement.

This project demonstrates **data storytelling using Tableau**, showcasing how raw review data can be turned into meaningful business intelligence.
